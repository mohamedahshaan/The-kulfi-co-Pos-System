THE KULFI & CO - NO DATABASE POS SYSTEM

How to use:
1. Open index.html in Chrome.
2. Put item photos inside the images folder.
3. Go Items page and enter image filename, example: mango_ice_pop.jpg
4. Bill and print using Print button.

No database needed.
Data is saved in browser localStorage.

Printer:
- Chrome print -> More Settings -> Headers and Footers OFF
- Margins None
- 80mm thermal printer
